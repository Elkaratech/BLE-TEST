How to read this

Typical = the middle signal reading, in dBm. Closer to 0 is stronger (−60 is stronger than −85). Weak 10% = the level that 1 in 10 readings fell below. Use it as the threshold you can rely on. Heard = the share of seconds with at least one packet. A spot with a low Heard percentage is a spot where attendance could miss the beacon.

Set up Chrome (once)

      
    
        
  1. Use Chrome on Android and open this page from its https link.
    2. 
        
  2. In the address bar type chrome://flags/#enable-experimental-web-platform-features, set it to Enabled, then tap Relaunch.
    3. 
        
  3. Switch Location on (quick settings). Android needs it for Bluetooth scanning.
    4. 
        
  4. Switch Bluetooth on. When Chrome asks, allow Nearby devices.
    5. 
        
  5. Keep Chrome open and the screen on while testing. The page asks the phone not to sleep.
    6. 
        
  6. If scanning stops by itself: Settings → Apps → Chrome → Battery → Unrestricted.
    7. 
      

    

    

      
Tips for a good test

      
    
        
  1. Mark spots on the floor first: 1, 3, 5, 8 and 12 m from the beacon, plus the corridor.
    2. 
        
  2. Stand still while recording. Keep the phone the same way for each spot.
    3. 
        
  3. Repeat with the phone in a pocket and a bag, since students will not hold it up.
    4. 
        
  4. Put the beacon where it will really be mounted, and keep it there for the whole test.
