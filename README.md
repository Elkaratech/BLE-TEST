# BLE range test

A single-page tool (phone-first) for measuring how strongly an Android phone hears a Bluetooth beacon at different distances. It is a test tool for the MUNKY BUNKY attendance project, not part of the attendance system, and it contains no accounts or data.

Open the page in **Chrome on Android**, then:

1. Go to `chrome://flags/#enable-experimental-web-platform-features`, set it to **Enabled**, and relaunch Chrome.
2. Turn on **Location** and **Bluetooth**, and allow **Nearby devices**.
3. Press **Start scan**, track the beacon, and record at each marked spot.

There is a demo mode that works without a beacon.
